## Sobre o projeto

A Encanto Fashion é uma loja fictícia de acessórios femininos criada para o Desafio 1 — Minha Loja: Simulador de Compras. O projeto permite conhecer os produtos, informar as quantidades desejadas e simular o valor de uma compra.

## Produtos e preços

- **Bolsa elegante:** R$ 80,00
- **Óculos de sol:** R$ 35,00
- **Brincos delicados:** R$ 20,00

Compras a partir de R$ 100,00 recebem 10% de desconto.

## Tecnologias utilizadas

- HTML5: estrutura da página.
- CSS3: cores, organização e estilo visual.
- JavaScript: perguntas, cálculos, desconto e resultado da compra.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Clique em "Simular minha compra".
4. Informe a quantidade de cada produto. Digite 0 para não comprar um item.
5. Confira o subtotal, o desconto e o total.
